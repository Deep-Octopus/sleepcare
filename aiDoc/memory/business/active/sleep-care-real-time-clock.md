# 睡眠康养：本地运行真实时钟

## 基本信息

- 提出日期：2026-08-19
- 当前状态：`active`
- 确认状态：已由用户要求修复
- 需求类型：本地运行一致性 / 缺陷修复
- 优先级：P0

## 用户原始意图摘要

日常交互环境应同步使用真实系统时钟，使前端刚创建的责任关系、任务和其他时效事实能够立即按当前状态参与后端查询，不再受阶段验收固定时钟影响。

## 范围与约束

- Compose 默认显式传入空的 `GVA_CARE_FIXTURE_NOW`，服务端使用系统时间。
- 显式空环境值必须覆盖已有配置卷里保存的固定时间，避免要求重置配置卷或业务数据。
- 可重复验收仍可通过显式 RFC3339 值按需启用固定业务时钟。
- 不修改数据库模型、状态机、生产 API 或权限边界。
- 不启用真实短信、用户侧 AI，也不增加医疗内容。

## 实现与验证

- Compose 默认值改为可选环境变量，未设置时明确使用系统时钟。
- 配置加载保留该环境变量的显式空值语义，从而清除持久化固定时钟的运行时影响。
- 配置契约、空值覆盖和时钟回退均由定向回归测试覆盖。
