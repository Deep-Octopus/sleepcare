## 用户原始意图摘要

呼吸机夜间数据在自动接口可用前支持规范人工记录，后续通过稳定 adapter 接入厂商。

## 影响范围

- 后端：`device`、原始事件和标准化 Observation
- 前端：人工设备数据记录和趋势展示
- 文档：字段、单位、时区、来源和更正规则
- 插件 / 模块：普通 package + 厂商 adapter

## 涉及对象

- 模块：device
- 接口：record、revise、import、query
- 页面：任务设备记录、数据历史
- 配置：厂商映射、单位、幂等和故障降级

## 工程实施基线（真实能力受门禁约束）

- 阶段一/二人工记录是正式降级能力，必须标来源和录入人。
- 更正追加修订，不覆盖原值。
- 厂商原始载荷追加保存，标准化后再供业务使用。
- 设备 adapter 不直接关闭事项或改变计划。
