# 睡眠康养：移动端受限访问

## 基本信息

- 提出日期：2026-08-18
- 当前状态：`active`
- 确认状态：工程实施基线已确认；正式业务、医疗与真实能力按 `docs/需求文档 r2.md` 第 16.2 节门禁启用
- 需求类型：移动用户体验 / 安全
- 优先级：P0
- 需求文件：`aiDoc/memory/business/active/sleep-care-mobile-access.md`

## 用户原始意图摘要

康养用户通过少步骤、老年友好的移动网页安全访问本人任务并完成填写。

## 影响范围

- 后端：一次性 grant、受限会话和康养用户接口
- 前端：独立移动布局和 client 路由
- 文档：身份、链接、断点续填和兼容范围
- 插件 / 模块：同一 Vite 工程的独立布局，正式 App/小程序后续立项

## 涉及对象

- 模块：client access
- 接口：redeem、tasks、questionnaire、draft、submit
- 页面：访问校验、我的随访、填写、提交成功和异常状态
- 配置：grant 有效期、会话时长和目标设备

## 工程实施基线（真实能力受门禁约束）

- 康养用户端不进入 GVA 员工动态菜单，也不复用员工 Token 语义。
- URL 不暴露姓名、病种、任务或长期凭证。
- 后端从会话推导用户/任务范围，不信任客户端 ID。
- 提交必须幂等，成功页只表示已提交而非已处理。

## 当前进展
