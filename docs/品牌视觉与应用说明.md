# 睡眠康养随访品牌视觉与应用说明

## 1. 品牌定位

品牌名称统一使用“睡眠康养随访”，用于表达本项目面向康养用户、健康管家、医护与督导人员的持续服务协作能力。

品牌短句为“让持续关怀有路径”。它强调任务、责任、处理和复盘都有清楚去向，不表达诊断、治疗效果或人工响应时限承诺。

## 2. 标志概念

标志由两部分组成：

- 月相环抱：对应睡眠场景，也表达安心、克制和持续陪伴。
- 三节点连续路径：对应康养用户、健康管家与医护之间的责任接力；末端金色节点提示需要关注的关键时刻，但路径不会因此中断。

界面配套使用五节点服务轨迹“计划—任务—关注—协作—复盘”，对应系统从服务安排到过程复盘的核心闭环。

## 3. 色彩

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 深松绿 | `#174F47` | 标志主体、可靠与安定感 |
| 雾青 | `#82B8A9` | 连续服务路径、协作关系 |
| 晨光金 | `#D6A55B` | 关键关注节点，少量使用 |
| 云白 | `#F5F1E8` | 月相和标志内高对比元素 |
| 墨青 | `#18312C` | 品牌文字参考色 |

界面控件仍使用项目主题语义色，不用上述固定色覆盖按钮、状态或告警语义；固定品牌色只用于标志资产本身。

## 4. 资产与规格

- 标志文件：`web/src/assets/brand/sleep-care-mark.svg`
- 品牌组合组件：`web/src/components/sleep-care-brand/index.vue`
- 服务路径组件：`web/src/components/sleep-care-brand/feature-path.vue`
- 建议最小显示尺寸：图形标志不小于 `20px`；带中文名称时图形不小于 `32px`。
- 标志四周至少保留图形宽度四分之一的净空，不拉伸、不旋转、不改变节点位置。

## 5. 当前应用位置

- 登录页：在原有框架品牌下方展示项目品牌、五节点服务路径和三项产品特色；原有框架标志、右侧品牌画面及版权信息保持不变。
- 员工工作台：展示项目标志和“计划—任务—关注—协作—复盘”路径，帮助非技术人员理解工作闭环。
- 康养用户移动端：在所有受限访问页面的固定页头展示项目标志和名称。

## 6. 内容边界

- 不使用医疗十字、处方、器械或诊断结论作为品牌符号。
- 不把 AI、正式短信或设备自动接入作为当前品牌承诺。
- 不在标志或品牌短句中暗示急救、疗效、全天人工响应或替代专业判断。
- 项目品牌作为业务身份补充展示，不替换或削弱基础框架已有的品牌、署名、授权提示和链接。
